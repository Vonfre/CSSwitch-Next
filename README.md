# CSSwitch Next

一个用于 Claude Science 的 macOS 第三方 API 管理与切换工具。

- 自行添加 API 提供商，管理连接和密钥。
- 自动获取模型列表，选择模型并测试连接。
- 在官方模式与第三方 API 之间切换，沿用本机对话记录。
- 支持 Anthropic Messages、OpenAI Chat Completions 和 OpenAI Responses。
- 查看用量趋势、模型统计、缓存用量和预估费用，筛选与导出请求记录。
- 搜索、阅读和导出 Science 本地会话，在 CSSwitch 中收藏、归档和调整显示名称。
- 管理 Science Skills，从本地及 GitHub 仓库发现并安装技能。
- 查看运行日志。
- 管理本地与远程 MCP，支持预设、筛选和标准 JSON 导入，内置科研数据库连接器。
- 在应用内检查、下载并安装更新。
