# CSSwitch Next 本机优化与后续规划

核验日期：2026-10-20。核验开始时安装的是 CSSwitch 0.8.0；本轮优化覆盖 0.8.1–0.8.3，本机当前已安装 0.8.3，尚未发布新版安装包。

## 本机现状与优先判断

Claude Science 应用包版本为 0.1.25，实际启动的是 `~/.claude-science/bin/claude-science` 自动更新版本 0.1.67，完整运行资源也是 0.1.67。这里的“当前版本”指本机实际版本，未据此宣称是官方最新发布版本。

现有提供商、Skills、会话、用量与 MCP 功能已经较完整，下一步优先提高更新后的可诊断性和日常打开速度。仅依据应用包版本或“已安装”无法判断适配状态。0.1.67 的 24 个本机连接器实际暴露 219 个工具，旧版记录为 225 个，说明工具数量也不能写成永久不变的兼容要求。

## 本轮已实现：0.8.1

| 改动 | 用户收益 | 实现边界 |
| --- | --- | --- |
| Science 兼容性面板 | 看清实际版本、应用包版本、运行资源和依赖；失败时知道如何处理 | 只读检查版本、CLI 参数与本地文件；不宣称所有远程服务已可用 |
| 重新检查与报告导出 | 更新 Science 后可以复查，排障时便于提供信息 | 报告排除密钥、对话和本机路径；不自动上传 |
| 启动阶段与耗时 | 区分网关、配置、Science、连接器和页面阶段 | 使用后端真实阶段事件，不显示推测百分比，不自动中断慢启动 |
| 复用已运行的服务 | 再次打开页面不再重复接入 24 个 MCP | 首次启动自动接入；失败的连接器可在 MCP 管理手动修复 |
| 预览服务空闲端口 | 降低 Science 主端口相邻端口被占用时的启动冲突 | 保留原生独立预览服务及安全隔离 |
| 实际应用版本号 | 侧栏不再残留 0.7 文案 | 与后端构建版本保持一致 |

## 后续已实现：0.8.2–0.8.3

- 设置页改为分组布局、细分隔线和右侧对齐控件，次要说明通过问号查看。

- 最终界面回归 61 项通过，设置专项 9 项通过；0.8.3 本机构建及签名校验通过。

## 下一阶段：0.9，按顺序推进

| 优先级 | 工作 | 验收方式 |
| --- | --- | --- |
| P1 | Science 更新差异检测：保存上次检查版本，启动前显示版本/资源变化 | 只提示发生的变化；更新下载未完成不误报可用，不自动重启研究任务 |
| P1 | 连接器能力快照：比较工具名、参数及资源 URI 的新增、移除和变化 | 以本机 `tools/list` 为依据；不固定工具总数，不复制 Science 实现源码 |
| P1 | 分层连接验证：普通回复、流式响应、工具调用、长上下文分别记录结果 | 每项分别显示“通过/失败/未测试”；真实模型探测由用户明确触发并说明费用 |
| P1 | 启动错误分类：端口冲突、数据目录迁移、版本不匹配、连接器失败、页面入口失败 | 保留具体原因和重试入口；研究任务运行时不自动重启 |
| P2 | 长任务体验：首字时间、进行中请求、工具执行阶段、断线后的状态恢复 | 对进行中请求只读观察，不自动重发有副作用的工具调用 |
| P2 | 会话与研究材料：按项目恢复上下文、定位产物、查看工具失败及重试来源 | 适配实际数据库模式；原始会话保持只读，导出结果保留引用与执行顺序 |
| P2 | 汉化覆盖巡检：新增设置和菜单的差异报告 | 对话、代码、数据库名称和编辑内容保持原文；仍可即时关闭恢复 |
| P3 | 可靠性收尾：提供商配置备份恢复、密钥存储优化、受支持的旧版回退流程 | 恢复前展示变更；迁移保留可恢复备份；不自动替换官方身份或历史数据 |

暂不扩大默认连接器数量，也不在每次打开页面时做全量外部网络探测。优先确保现有 24 项与用户安装的 Science 资源一致。新版适配采用可复现的协议、页面和文件结构证据，而不是只比较版本号。
