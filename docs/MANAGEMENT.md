# 管理工作空间

MCP、Skills、用量和会话管理的导航、列表筛选和视觉风格参考 [cc-switch](https://github.com/farion1231/cc-switch)。本轮参考版本为 `d9a62313c8a276216ed40245c638753606831e95`。功能面向 Claude Science，使用本项目的 HTML / CSS / JavaScript、Tauri 命令和 Science 管理接口实现。

## MCP 管理

启动「提供商 → 第三方 API」管理的 Science 后，可搜索连接器，按来源或绑定状态筛选，添加本地 stdio / 远程 HTTPS 服务，管理 Science 绑定、工具权限及 OAuth 授权。

添加窗口提供 Filesystem、Memory、Fetch 快速配置。Filesystem 的允许目录需要自行填写；npm / uvx 软件包及其运行环境需要先安装。本地命令支持绝对路径或 `npx`、`uvx` 等已安装命令，桌面端会解析可执行文件路径。

「导入 JSON」接受标准配置：

```json
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    },
    "research": {
      "url": "https://example.com/mcp",
      "type": "http"
    }
  }
}
```

一次导入 1 至 30 个服务，先校验全部配置，再逐项导入。同名服务跳过；部分失败时保留成功项并逐项展示结果。完成后清空含环境变量的 JSON 草稿。远程配置中的静态 `headers` 需要改用添加窗口的 Science `headers_helper`，避免静默丢弃认证。

## Skills 管理

0.7.1 使用紧凑列表和多选工具栏。勾选单项或「全选当前页」后，可批量安装、启用、停用、卸载或更新。搜索只匹配技能名称（包括显示名称），不匹配描述或仓库；「统一技能库」按未安装到所选目标优先排列，已安装技能仍保留在后面。每页 50 个 Skills，已安装和统一库均提供数字页码、上一页 / 下一页及输入页码跳转；搜索、来源和状态筛选保留选择，切换视图或目标时保留各自的筛选。受组织策略限制的技能不可选择；批量操作逐项执行，失败或不可操作的项目单独报告，成功项保留。

「导入 Skill」可一次选择最多 50 个文件，也可选择包含多个 SKILL.md 的集合 ZIP。集合 ZIP 先校验所有技能，再拆为完整的独立技能包；每项保留 references 和 scripts，最多 50 个技能，原始压缩包最多 4 MB、集合解压最多 16 MB，单技能仍受 4 MB / 1000 文件限制。同名项目不自动覆盖。

「检查更新」同步已添加的 GitHub 仓库，再比较已管理技能与原来源的完整文件哈希（包含辅助文件）。存在差异时可单项、更新所选或「全部更新」。仅替换 CSSwitch 所有的本地草稿；安装来源、内容指纹和组织策略均需匹配。已有本地修改、来源不明或仓库同步失败时跳过。替换前保留完整旧目录，Science 验证新内容后完成更新；验证失败恢复旧文件。原有代理绑定和启停状态保留。通过文件导入而无可关联来源的技能，可在导入新版文件时勾选「更新通过文件导入的同名本地技能」进行批量更新，仍校验内容指纹、跳过本地修改并保留旧目录用于验证失败回滚。Science 官方及组织技能继续由其原生权限管理。

「已安装」读取 Science 技能目录，可查看并导出 SKILL.md、启停技能和卸载可管理的技能。必需技能和组织策略由 Science 验证，组织禁用项显示为不可操作。

「统一技能库」直接扫描常见本机 Agent 的 Skills 目录，并展示已添加 GitHub 仓库中的技能；完整支持范围见下方统一技能库说明。服务停止时仍可发现和管理本机技能；安装、启停和读取 Science 技能内容需要启动第三方 Science。

仓库管理支持公开 GitHub `owner/repo` 或仓库 URL、分支、手动同步及移除。0.8.10 起取消仓库整体 ZIP 下载体积、解压总量及文件数量限制，按 1 MB 分块写入临时文件，校验通过后替换缓存；仓库保持压缩状态，只读取技能说明和所选技能，不展开无关大文件。下载失败会清理临时文件并保留原缓存，下载最多等待 10 分钟。macOS 与 Windows 使用相同逻辑；扫描和打包不会执行技能代码。安装所选技能时包含其 references、scripts 等辅助文件，跳过本地隐藏文件、依赖目录和技能内部的符号链接；顶层技能目录链接在已登记来源内解析并去重。单个技能包上限 4 MB / 1000 文件。

也可直接导入 `.zip`、`.skill`、`.md` 文件。Science 会检查包结构、技能名称、同名冲突及组织策略；CSSwitch 不覆盖同名技能。0.6.1 起，Science 云端目录处于 degraded 状态时，导入自动使用本地技能草稿目录 `data_dir/orgs/<当前组织>/skills`。支持 Markdown / ZIP / .skill，保留 references 和 scripts；SKILL.md 必须包含唯一的 name 与非空 description，名称符合 Science 的小写字母 / 数字 / 短横线规则（最多 64 位）。安装前核对组织策略，拒绝覆盖已有目录、内置技能及发布缓存；不生成 `.catalog_stamp` 或伪造发布来源。安装后由 Science 原生接口核验草稿和内容并绑定 OPERON，绑定失败撤销本次安装。隐藏来源标记、路径穿越、符号链接、特殊文件及过大的压缩包会被拒绝。

已安装列表同时展示本地草稿，并只读查询 Science 的启停状态。CSSwitch 自己安装的本地技能可在目录断连时卸载，先由 Science 解绑代理，再删除其本地文件；其他技能的删除继续交由 Science 校验。云端发布仍需有效官方登录。移除仓库保留 Science 中已安装的技能和惰性 ZIP 缓存。

## 用量统计

用量来自 CSSwitch 本地网关，最多读取最近 2000 条记录。总览包含请求、输入 / 输出 Tokens、缓存读取、平均耗时、成功率、每日趋势和模型汇总。请求列表每页 25 条；CSV 导出完整的当前筛选结果。可按今天、7 天、30 天、全部记录、提供商和模型筛选。

模型定价按 USD / 百万 Tokens 配置输入、输出、缓存读取和写入单价，保存在 CSSwitch 配置目录的 `workspace.json`。预估费用随定价更改重新计算；未定价的请求不计入费用并显示缺失数量。OpenAI Chat / Responses 输入中包含的缓存 Tokens 会从普通输入计费中扣除，Anthropic 缓存用量单独计价。新记录保存调用时协议和缓存写入计数，旧记录协议使用当前提供商配置推断。

统计仅覆盖通过网关的请求，不包含官方模式或绕过网关的调用；预估费用不代表服务商账单。趋势在「全部记录」中显示最近一次记录之前的 14 天，在其他时间范围中显示截止今天的最近 14 天（7 天和今天分别显示 7 天和 1 天）。

## 会话管理

0.7.1 会话采用 cc-switch 式列表与独立阅读页。首页全宽显示项目折叠组或时间分组，支持标题、项目、首末消息与会话 ID 搜索、收藏 / 归档和项目筛选。点击后进入全窗口阅读页，顶部显示项目、起止时间、已加载提问 / 工具调用数与模型，并可切换相邻会话。提问靠右显示，Science 回复按轮次归并，执行过程可折叠；工具调用根据原始 ID 与结果配对，展示明确的失败状态。展开查看参数 / 结果，长输出先展示 8 行并可显示全部。支持 Markdown、表格、代码复制、对话 / 改动 / 工具筛选、内容搜索与对话目录。「改动」筛选已加载的 Edit / Write / apply_patch 等文件修改工具调用，不推断缺失的文件差异。内容搜索只覆盖已加载消息；「加载更多消息」扩大读取范围，导出始终读取完整会话。返回列表保留筛选、搜索、分页与项目折叠状态。所有 Markdown 本地渲染、HTML 转义并清理，图片仅显示附件提示，不自动加载远程资源。

读取 Science `data_dir/orgs/*/operon-cli.db` 的主会话、项目和消息。数据库以 SQLite `mode=ro` / `query_only` 打开，服务停止时也可浏览。支持标题 / 项目 / 模型搜索、项目筛选、时间或项目分组、每页 25 个会话。

点开会话后分批读取 100 条消息，显示文本和工具调用 / 结果。导出 Markdown 时逐批获取整段会话，每条消息最多 60,000 字符，截断时明确标记；图片等附件保留类型提示，不导出二进制数据。

收藏、归档和显示名称只写入 CSSwitch 的 `workspace.json`，原始 Science 数据库保持完整。每个组织最多扫描最近 5000 个主会话；不可读或版本不兼容的数据库显示警告，其他组织的可用记录仍可浏览。

## Science 插件与本机 MCP

0.8.2 将两个独立开关按用途放在对应页面：**使用本机 MCP** 位于 MCP 管理页；**Science 页面汉化** 位于设置页。调整其中一个不会改变另一个。

- **使用本机 MCP** 默认开启。第三方 Science 启动时核对 24 个本机服务资源，沿用 20 个原生本机连接器，接入 PubMed、bioRxiv、ChEMBL、Clinical Trials 的本机版本并停用其 Claude 托管版本。不创建审批豁免，保留原生服务 ID、绑定、凭据及手动启停状态。旧 csswitch-openscience 配置在替代服务就绪后先私密备份再移除。MCP 管理显示实际连接状态，支持接入修复及 24 项无密钥配置导出。参见 [MCP 管理](MCP.md)。
- **Science 页面汉化** 默认关闭。CSSwitch 为第三方 Science 建立回环浏览器入口，支持本地翻译、Edge 自动翻译和 AI 自动翻译；旧配置默认本地翻译。已有准确译文与缓存优先，新界面文案可联网补全。配置在 3 秒内同步到已打开的入口页面，保留 React 节点结构；代码、原生 `.markdown-content` 对话 / 文档、可编辑内容与输入值不会被翻译。未覆盖且无法翻译的文案保留英文。关闭时仅恢复仍保持译文的节点，避免覆盖 Science 新渲染的内容。接入方案、数据范围和验证见 [自动汉化](TRANSLATION.md)。

旧浏览器标签页请从 CSSwitch 再次打开。此插件覆盖该入口中的页面和弹出菜单，不修改官方应用二进制，也不作用于官方原生客户端窗口。页面反向代理固定转发到当前本地 Science 端口，校验 Host / Origin，保留本地认证、CSRF 与工具审批；第三方服务的密钥不会提供给汉化脚本。关闭 CSSwitch 会停止页面入口与模型网关。

验证：`python3.11 -m unittest discover -s scripts/tests`、桌面 Playwright 与 Rust 测试；macOS 可运行 `python3.11 scripts/probe-science-connectors.py --prototype` 和 `python3.11 scripts/probe-science-ui.py`，在独立 HOME、独立端口和仅回环网络的测试实例中检查真实工具调用、页面认证、WebSocket、语言恢复及对话正文保护。

## Science 模型自动映射（0.8.4）

CSSwitch 读取本机实际启动的 Science 可执行文件，只提取公开模型 ID、名称及默认标识；文件被更新后重新识别，不复制其实现代码。Opus 对应质量模型，Sonnet 对应默认模型；质量未指定时继承默认模型。Haiku／快速配置已移除，旧会话或后台 Haiku 请求兼容使用默认模型及协议。新的系列版本号、日期后缀和旧会话 ID 均按系列转发，已有请求沿用发出时的配置。

Science 的「默认模型」表示新会话选用哪个原生档位，并不与 CSSwitch 的「默认模型」字段同义。例如 Science 默认选 Opus 时，实际调用 CSSwitch 的质量模型。菜单显示「原模型 → 实际模型」，审阅和子代理同样按其所选原生模型路由。

保存连接后，新请求立即使用新映射；已打开的 Science 页面需刷新以更新菜单。菜单缓存同步仅作用于 CSSwitch 第三方页面的常规模型目录，保留原生选择、可用性标记、组织策略目录和错误信息。未识别出目录时使用已知标识；若 Science 引入新系列或更改目录格式，仍需验证适配。

可运行 `python3 scripts/probe-science-ui.py --models`，在独立 HOME 和仅回环网络的实例中验证默认、审阅、菜单及配置刷新，不调用外部模型或修改现有研究实例。


## 同一连接混用 API 协议（0.8.5）

编辑提供商 → 模型，在质量模型名称旁选择 API 协议。默认模型使用「连接」页的协议，质量模型默认「跟随连接」。例如连接使用 OpenAI Responses、默认模型填写 GPT、质量模型填写 Claude 并选 Anthropic Messages，即可在不同 Science 对话中同时使用。模型留空时同时继承默认模型和协议，不向 Claude 端点发送继承的 GPT 模型。

各档位共用原连接地址与 Key，仅按协议选择 `/responses`、`/chat/completions` 或 `/messages` 端点；完整推理地址会保留 API 路径前缀并替换末尾端点。此功能需要服务商在该地址支持所选协议，不根据模型名称猜测其服务能力，也不会自动回退并重复发送请求。不同地址或不同 Key 的跨提供商组合不在本次范围内。

「测试」页可选择默认、质量档位，测试未保存的配置；模型选择器按当前档位的协议获取目录。模型路由和协议在每个请求开始时一起确定，保存后影响后续请求，流式响应和正在运行的请求继续使用原配置。


## 统一技能库与本机 Agent（0.8.6）

实现参考 [cc-switch 的 Skills 服务](https://github.com/farion1231/cc-switch/blob/main/src-tauri/src/services/skill.rs) 的主副本和按应用分发方式：导入先复制到统一库，再以自动、软链接或复制方式分发。CSSwitch 使用自己的管理索引、文件校验和桌面界面。

使用步骤：

1. 打开「Skills 管理」，直接进入合并后的统一技能库。本机及已登记仓库的技能自动展示，无需手动入库；「本机目录」显示路径、技能数和链接数，可添加自定义目录。
2. 选择安装目标。菜单显示目标实际目录中的技能数量；来源筛选显示各来源的技能数，状态筛选可只看目标中已启用或未启用的技能。搜索只匹配名称，分页与勾选支持跨页。
3. 点击「一键启用 N 个」，对当前来源、名称和状态筛选中的所有页生效。已有技能保持内容，缺失项自动建立私有副本并分发。全部启用后，不需要的技能可逐项关闭，也可勾选后批量停用。
4. 原有目录或链接关闭时改名为同目录下 `.csswitch-disabled-<随机标识>`，索引记录原路径与文件身份；再次开启恢复原目录，保留相对链接和原文件内容。若备份被替换、原位置出现同名新目录，恢复会拒绝覆盖。其他 Agent 正引用原目录时会阻止停用该目录，避免破坏它们的链接。
5. 新分发默认优先软链接，可在「分发方式与说明」中改为复制。统一副本的「同步原来源」仍可更新主副本，软链接跟随；复制分发须先停用后更新再开启。Science 的更新、原生导入与卸载在「Science 已安装」中管理。

默认发现路径：

| Agent / 来源 | Skills 目录 |
| --- | --- |
| Codex / 系统技能 | `~/.codex/skills` / `~/.codex/skills/.system` |

同名技能合并为一行。目标已有技能保留其内容；新安装优先选择统一副本，否则选择当前来源中的第一个版本。需要指定版本时先筛选来源；同名不同内容与统一副本冲突时报告错误，不静默覆盖。

统一副本位于 `~/.csswitch-next/skills`，索引位于 `~/.csswitch-next/skill-library.json`，移除备份位于 `~/.csswitch-next/skill-backups`。导入不执行技能代码，原目录保留。每项最多 4 MB / 1000 个文件；本机脚本可执行标记在入库和复制分发时保留。读取和导入不会更改现有 Agent 的技能。

各 Agent 可能同时读取共享目录或缓存技能列表，开关仅表示 CSSwitch 管理的目标目录状态。其他管理器可能重新创建被停用的原目录，此时显示实际状态，恢复备份时拒绝覆盖。Agent 是否需要重载由该 Agent 决定。Science 采用原生接口复制安装，保留组织策略、绑定和启停校验；Science 副本的更新在「Science 已安装」中执行，移出统一库不会卸载该副本。Science 的名称格式限制仍独立生效。

## 生成文件本地打开（0.8.6）

在「设置 → 通用」开启「本地文件打开」，然后从 CSSwitch 提供商页打开 Science。生成文件卡片的右键菜单、文件库菜单和预览的更多操作菜单会增加：

- **在文件夹中显示**：Finder 直接定位当前版本的实际文件。
- **用默认应用打开**：PDF、Office 文档、图片、常见数据与文本文件使用 macOS 默认关联应用。
- **用文本编辑器打开**：使用 macOS 默认文本编辑器（`open -t`），适用于 Markdown、代码和其他文本。

插件默认关闭，与汉化和本机 MCP 分别保存，切换后页面约 3 秒内生效。首次升级到包含此插件的版本，需要重启 CSSwitch，再从提供商页重新打开 Science；有研究运行时先等待任务结束。仅 CSSwitch 的本地浏览器入口提供此功能，官方客户端窗口和直接打开原生端口的页面不加载插件。

实现参考 [417CS-tools](https://github.com/lucien-ho/417CS-tools/tree/2a460f904c47310f84df01f390efe33622ffe2f9) 所展示的本地文件打开流程，独立实现 macOS 页面插件与本地接口，无需安装 Edge 扩展或 Windows 原生组件。读取当前菜单的原生文件标识，通过现有 Science 登录获取 `/api/artifacts/{id}/metadata` 中的 `file_path`；历史版本精确匹配版本列表中的 `artifact_id` 和 `version_id`，不拼接存储路径、不按文件名寻找、不回退到最新版。内容去重后的实际存储位置同样可用。

只支持 Science 存储记录指向的、仍存在的普通本地文件。远程引用、没有存储记录的直接本地引用、多文件选择以及无法识别的菜单会提示使用原生操作；不自动下载、缓存或产生副本。缺失历史版本也不会打开其他版本。默认应用入口不执行脚本或程序，代码可选择文本编辑器，其他格式可先在 Finder 中显示。

打开的是实际文件，编辑后保存会改变该文件；Science 内部存储文件的版本校验或预览缓存可能受影响。需要保留原结果时可在编辑器里另存为。CSSwitch 本身只读取存储记录和文件状态，不修改生成文件，也不上传文件内容。

本地操作接口仅监听回环地址，校验 Host、Origin、页面操作令牌与 Science 登录，仅接收文件标识、版本和三种操作，不接受任意路径或命令。启动应用使用参数数组，不经过 shell；错误不返回认证信息。测试用临时文件和模拟系统启动调用，不打开用户文档。

本地验证：73 项界面测试通过；108 项 Python 管理测试中 104 项通过、4 项可选测试跳过；Rust 测试 70 项通过、3 项忽略。补充回归覆盖当前原生预览组件的 161 个 hooks。隔离 Science 实例中验证生成文件右键菜单和预览更多操作、文件版本与真实存储路径，以及独立关闭插件；未启动外部应用或下载文件。最终菜单回归 7 项和入口代理回归 12 项通过，本地 App 构建与签名校验通过。

Skills 界面进一步统一：两个视图保持相同的页签顺序、工具栏、目标栏、筛选和列表列宽。预览、更新、卸载与开关集中到操作列，开关固定在右侧。移除重复小标题，描述显示单行摘要（悬停可查看全文），批量说明与目录降级信息按需展开。导入与检查更新均作用于 Science；统一库仍保留按目标一键启用、名称筛选、分页和未安装优先。桌面与窄窗口、浅色与深色均验证无横向溢出。

补译 Science 文件菜单的 Provenance（来源追溯）、View in context（查看上下文）及相关标题与提示；关闭汉化后恢复原文，研究正文不变。此次 Skills、汉化与本地文件菜单共 41 项界面回归通过；0.8.6 发布前完整界面测试共 75 项通过。


## Science 模型映射（0.8.7）

在 CSSwitch「提供商 → 编辑 → 模型」中设置实际模型：Sonnet 对应默认模型，Opus 对应质量模型。质量模型可独立选择 API 协议；模型留空时继承默认模型及其协议。支持从已保存的 API 连接获取模型列表，也可手动输入模型 ID。接口返回的可选模型数量不代表 Science 菜单数量或已配置的映射数量。保存后后续请求立即采用新映射，进行中的请求保留开始时的配置。

Science 网页保留原生聊天框与设置中的默认、子代理和审阅模型选择器；这些入口只选择原生模型档位。实际提供商、API 模型和协议统一由 CSSwitch 控制。网页不再注入自定义模型弹窗或悬停二级菜单，也不再提供修改映射的接口。

模型数量、顺序、可用状态及「更多模型」分组以 Science 当前官方目录为准，每项显示「原模型 → 映射模型」，例如「Opus 5 → gpt-6-astra」。完整保留旧版本模型条目，不把内部使用的模型或历史映射加入菜单。旧版 CSSwitch 写入的目录会从本机安装目录刷新；受组织策略管理的模型目录保持原生行为。

早期本地试用版在会话中保存的版本 99 模型标识，继续按其 Opus、Sonnet 档位路由，Haiku 则兼容使用默认模型，但实际目标统一跟随 CSSwitch 的当前配置。旧记录中的提供商、模型和协议不再生效；即使旧连接已删除，也无需重新创建该独立映射。页面读取会话元数据与模型偏好时，将旧标识还原为同档位的原生模型，同时迁移浏览器中的旧选择缓存，避免增加重复选项；旧记录和 Science 对话数据均不改写。

跨协议使用旧对话时，网关在发出请求前规范工具调用 ID，并同步转换对应结果的 ID，保留原始聊天记录。上游参数错误和请求过大保留 400、413，不再转为临时 502；503 内存过载及 SQLite 额度预扣锁定明确提示当前 API 服务商故障。第三方模式下，重试状态不再链接到 Claude 官方状态页。

本地更新后刷新 Science 网页即可移除旧菜单；后台网关需加载新版路由。默认仍使用本机原有 Science 数据和会话记录。

原生界面探针 `scripts/probe-science-ui.py --models` 使用隔离 Science 和本地模拟 API，验证官方模型数量与分组、「原模型 → 映射模型」名称、原生选择器、质量与默认档位的不同协议、旧对话随 CSSwitch 配置热更新。探针成功停止隔离服务后自动删除测试沙箱；调试时可使用 `--keep-fixture` 保留，停止失败时保留目录以便排查。
